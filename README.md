# Sistema de Gerenciamento de Usuários

Aplicativo Java com interface gráfica (Swing/MDI) para cadastro de usuários, envio de notificações e controle de acesso.

## ✅ Funcionalidades

- Cadastro de administrador e usuários (com aprovação)
- Autenticação com login e senha
- Envio de notificações por administradores
- Visualização e marcação de notificações como lidas
- Alteração de senha
- Registro de atividades (log)

## ⚙️ Tecnologias e Padrões

- Java Swing (MDI)
- Banco de dados SQLite
- Padrões de projeto: **State**, **DAO**, **Command**, **Adapter**
- Log em **CSV** e **JSON**
- Validador de senhas via JitPack
